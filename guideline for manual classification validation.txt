Manual Validation Guideline

Please classify each issue as 'feature' or 'not-feature' using only the problem_statement. Treat the first line as the title and the remaining text as the body. Ignore issue templates, contribution guidelines.

A 'feature' is a request to add, extend, or intentionally change the software's behavior or capability in terms of developer-facing functionality. Please note that in this dataset, all the systems are software library systems, therefore the functionality can be very specific to certain technical details.

A 'not-feature' is a request to fix, document, clarify, or discuss existing behavior rather than add or intentionally change capability. This includes bug reports, missing or unclear documentation, usage questions without a concrete request for a new capability.
